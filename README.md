## Возможности (+12)

### Player
- Infinite Health (`Num 1`)
- Edit Max Health (`Num 2`)
- Infinite Stamina (`Num 3`)
- Edit Max Stamina (`Num 4`)
- Infinite Spirit (`Num 5`)
- Edit Max Spirit (`Num 6`)

### Combat
- Edit Defense (`Num 7`)
- Super Damage / One Hit (`Num 0`)

### World
- Freeze Daytime (`Ctrl+Num 1`)
- Set Day Time / Skip (`Ctrl+Num 2`)
- Set Game Speed (`Num 9`)

### Items
- Edit Item / Money Amount (`Num 8`) — открыть инвентарь, выбрать предмет/деньги, задать значение, save & reload

1. Запусти **Crimson Desert**
2. Запусти трейнер
3. Дождись `CrimsonDesert.exe`
4. Категории: Player / Combat / World / Items
5. `Num` — вкл/выкл · `Ctrl+Shift+Home` — master off
